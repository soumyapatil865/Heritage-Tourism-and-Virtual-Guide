Heritage Tourism and Virtual Guide

**Overview**

Heritage Tourism and Virtual Guide is a web-based application designed to help users explore historical and cultural heritage sites with ease. The platform provides detailed information about tourist destinations, interactive maps, nearby facilities, and an AI-powered chatbot that acts as a virtual tour guide. The goal of this project is to promote tourism by making heritage information easily accessible through a user-friendly interface.

**Features**

🏛️ Explore famous heritage and historical places.

🤖 AI-powered chatbot to answer user queries about tourist destinations.

🗺️ Interactive maps with location and route guidance.

📍 Displays nearby restaurants, hotels, petrol pumps, and other essential services.

📖 Provides historical background, cultural significance, and interesting facts about each location.

🔍 Search and filter heritage sites for quick access.

📱 Responsive design for desktop and mobile devices.

👤 User-friendly interface with smooth navigation.
